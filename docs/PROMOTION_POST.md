# 我们把「观自在」的源码公开了：一个面向佛教典籍与古籍的现代阅读项目

我们一直在思考：古老的典籍，能不能拥有一种更安静、更清楚，也更适合今天读者的阅读方式？

于是有了 **观自在 Guanzizai**。

它是一个使用 Next.js、React 和 TypeScript 构建的现代典籍阅读项目。我们希望让读者始终从原文出发，在需要时获得白话释文、站内检索、出处定位和引用式问答等辅助，同时清楚区分原文、人工审核内容与 AI 辅助内容。

![观自在公开版阅读界面](https://raw.githubusercontent.com/AmigaMeow/guanzizai/main/docs/images/reader-demo.jpg)

目前公开的源码包含：

- 原文、释文和平行对照阅读；
- 分卷目录、段落定位、搜索与阅读导出；
- 书架、收藏、划线、阅读进度和账户功能；
- 基于已发布内容检索的问答与出处卡片；
- 内容导入、版本管理、质量检查、投稿与人工审核流程；
- 管理后台、数据库迁移及对象存储支持；
- 移动端与桌面端适配。

我们坚持三个原则：**原文优先、出处可核验、内容有边界**。AI 白话只用于辅助理解，不替代原文；未经真人核验的内容，也应该被明确标识。

这次公开的是经过脱敏的功能源码，不包含藏经阁书籍、真实译文、预生成回答、生产数据库、用户数据、支付信息或任何密钥。仓库只附带少量原创虚构文本，方便大家本地运行和了解项目结构。
